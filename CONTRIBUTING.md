# Contribution Guidelines

Thanks you for considering to contribute to the Native Wrapper Generator project.

## Using the issue tracker

> [!IMPORTANT]
> Please do not use the issue tracker to ask questions regarding how to use the software. Those are closed without further reply.

If you are here to report an issue, request a new feature or enhancement, use the [Issues](https://github.com/WithLithum/native-wrapper-gen/issues) section.

### Search for existing issues

Before you create a new issue, make sure that your report or request doesn't already exist.

To help you better find already existing issues, search relevant keywords _instead_ whole pharses or sentences.

### Create the issue

Once you are sure that there are no existing issue that corresponds to the problem or request you are going to raise, [click here to create a new issue](https://github.com/WithLithum/native-wrapper-gen/issues/new).
