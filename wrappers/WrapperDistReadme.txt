Native Wrappers for Grand Theft Auto V
(C) WithLithum 2025-2026

For use with Grand Theft Auto V Legacy only.

_______________________________________________________________________________

Information for Players
=======================

This is a dependency library, created for Grand Theft Auto V Legacy, that needs
to be installed for scripts mods that requires it.

Versions for Script Hook V .NET and RAGE Plugin Hook are provided.

_______________________________________________________________________________

Installation
============

The Native Wrappers needs to be installed into the Grand Theft Auto V directory
appropriately for the mods requiring it to function.


SHVDN version
-------------
Extract everything under the "shvdn" directory into the "scripts" folder,
within the game directory.


RPH version
-----------
Extract everything under the "rph" directory into the game directory.


_______________________________________________________________________________

Information for Developers
==========================

This library allows you to easily call native functions, as described on
alloc8or's NativeDB data (browsable via https://alloc8or.re/gta5/nativedb/),
without the need for manually writing 'Function.Call' or
'NativeFunction.Natives' calls.

However, not all natives can be conveniently generated. Functions that takes a
'char*' (mutable string pointer) are translated as 'IntPtr' and the burden of
managing such a pointer falls onto the caller.

NuGet packages are provided under the name of 'WithLithum.NativeWrapper'. All
natives can be accessed via the 'Natives' class.

This library is generated by the Native Wrapper Generator, available at
https://github.com/WithLithum/native-wrapper-gen.

_______________________________________________________________________________

Reporting bugs
==============

Players should first contact the mod which the problem appears to originate
from. Only report an issue to the Native Wrapper project when directed to do so
by the mod author.

Issues relating to the Native Wrapper may be reported to the following issue
tracker:

https://github.com/WithLithum/native-wrapper-gen/issues
